Privacy Policy & Terms of Service - Personal Automation Tool Privacy Policy & Terms of Service Personal Use Only Last updated: September 2026 This software is a private, non-commercial automation tool designed solely for personal workflow management and uploading authorized media content directly to the developer's connected social media accounts (including TikTok). 1. Non-Commercial & Personal Use Statement This application is developed strictly for internal and personal use. It is not distributed, sold, or offered as a public service or software-as-a-service (SaaS) to any third parties. 2. Data Collection and Usage Authentication Tokens: The tool uses OAuth 2.0 to access the TikTok API. Tokens (Access Token and Refresh Token) are stored locally on the user's private machine solely to authenticate API requests. User Profile Data: Basic profile information retrieved via the user.info.basic scope is displayed only locally to confirm account connectivity and is never transmitted externally. No External Storage: We do not operate external databases, remote tracking servers, or analytics services. No personal data, user credentials, or telemetry are ever harvested or logged outside the local runtime environment. 3. Data Sharing and Disclosure We do not share, sell, rent, or distribute any user data, tokens, or video files to any third-party companies, advertisers, or individuals. 4. Media Content and Publishing All video uploads initiated through the video.upload and video.publish scopes are explicitly triggered by the authorized account owner. The application does not publish unapproved content or modify uploaded video assets without explicit user action. 5. Data Retention and Deletion Since all credentials and tokens reside exclusively in local storage, disconnecting the application or deleting the local configuration files immediately and permanently erases all associated access tokens. 6.
