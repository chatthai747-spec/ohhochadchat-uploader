::: Technical Architecture & Capabilities :::

System Specifications & Routing

Technical architecture and automation logic for sorting, metadata formatting, and publishing Ohho Chadchat channel videos under a strict Local-First standard.

01

Smart Duration Routing

Automated Pipeline Routing

Analyzes video duration offline on the editing workstation via FFprobe immediately upon selecting a file, intelligently routing content to the appropriate platform according to duration requirements.

Duration ≤ 180 Seconds (≤ 3 Minutes)

Short-Form Multi-Distribution

Short-form clips are delivered simultaneously across all short-form platforms in one click:

  • YouTube Shorts (9:16 Vertical) ✔ Unlocked
  • Facebook Reels (Creator API) ✔ Unlocked
  • TikTok Video Publish (Content API) ✔ Unlocked
Duration > 180 Seconds (> 3 Minutes)

Long-Form Dedicated Route

Long-form clips are strictly locked to primary long-form destinations while disabling short-form queues:

  • YouTube Main Long-Form Video ✔ Primary Route
  • Facebook Reels (Excluded >3m) ✘ Auto-Disabled
  • TikTok Queue (Excluded >3m) ✘ Auto-Disabled
02

Unified Metadata Engine

Centralized Content Management

Centralized Content Inspector allows the production team to manage Title, Description, Timestamps, and Hashtags in one unified window without switching between applications.

📝

One-Stop Input Sync

Enter titles and descriptions once; character limits and platform formats are adapted automatically.

⏱️

Chapter Timestamps

Full support for video chapters (00:00, 02:45) for YouTube descriptions without cluttering TikTok captions.

🏷️

Smart Hashtag Processing

Aggregates core channel hashtags #OhhoChadchat and places them properly based on platform requirements.

03

Local-First Security Architecture

Zero Cloud Exposure & Safe Tokens

Security architecture engineered around Local-First principles, dedicated exclusively to studio workstations.

💾

Offline Token Storage

OAuth Refresh & Access Tokens are encrypted and stored 100% locally strictly on Ohho Chadchat's internal production workstations.

🛡️

Authorized API Endpoints

Content publishing requests are processed via authorized official API endpoints provided by Google, Meta, and TikTok.

🚫

Zero Public Telemetry

No analytics tracking, user behavior monitoring, or forwarding of video data to external servers.
